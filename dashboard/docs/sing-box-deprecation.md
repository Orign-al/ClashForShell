# End of sing-box support

zashboard will remove support for sing-box in 3.23.0. This includes the native
sing-box gRPC API as well as compatibility with the Clash API provided by sing-box.

## Why support is ending

I originally built this dashboard for fun in my spare time. I never expected some
self-appointed cyber emperor to start barking from the sidelines. I have no interest in
maintaining compatibility with a project like this anymore.

To zashboard users who rely on sing-box: I am sorry. I recommend switching to another
project.
